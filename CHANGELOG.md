# Changelog

## 0.2.0 (26 Nov 2026)

- `MenddFeedbackText.current`: apps set translated texts once; `friendlyError`, `SaveRunner` and
  `BusyButton` use them (Tamil-ready shared messages).
- `BusyButton` shows "Saving…" (translatable) while busy when no `busyLabel` is given.

## 0.1.0 (26 Nov 2026)

First version (Phase 3b-1): brand tokens sampled from `brand/`, `menddTheme`, accessibility
minimums (16/14 text, 48 dp targets, AA contrast), `BusyButton`, `SaveRunner`, `showMessage`,
`friendlyError`, `StateView`, `StatusPill`, `KeyValue`, `SectionHeader`, `RatingStars`,
`TestModeBanner`.
